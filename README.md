# 中距離ブロック

慶應義塾體育會競走部 中距離ブロックの予定共有・練習記録アプリ。

- ホーム：今日の予定（上に集合・予定、下に練習メニュー）とこれからの2週間
- カレンダー：部活の予定／練習予定／集合欠／個人（Google・Apple・Outlook カレンダー）
- 練習記録：週間走行距離、Slack のメニューを読み込んで記録、ブロック全体のメニュー
- 設定：Slack サインイン、部の予定のカレンダー配信（Apple／Google／Outlook）、個人カレンダーの連携

## データの置き場所

| データ | 置き場所 |
| --- | --- |
| 部の予定・集合時間の変更 | `data/schedule.ts`（全員に反映） |
| 部員・練習メニュー・集合欠 | Slack（#01_メニュー設定・#01_集合欠）から読み込み |
| 練習記録・個人カレンダー・端末で追加した予定 | ブラウザの localStorage（その端末のみ） |

公開と Slack 連携のしかたは [docs/SETUP.md](docs/SETUP.md) を見てください。

```bash
npm install
cp .env.example .env.local   # 必要なら Slack の値を入れる
npm run dev
```
