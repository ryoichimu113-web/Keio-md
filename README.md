# 中距離ブロック

慶應義塾體育會競走部 中距離ブロックの予定共有・練習記録アプリ（試作版）。

- ホーム：今週の走行距離・今日の記録・今日の予定・これからの予定（2週間）
- カレンダー：部活の予定／練習予定／集合欠／個人（Googleカレンダー）の4タブ、集合時間の変更、予定の追加
- 練習記録：週間走行距離のグラフ、月ごとの記録、ブロック全体の記録、記録の追加（`/log/new`）
- 設定：仮ログイン、管理者画面（`/admin`）、Googleカレンダー連携、Slack連携

データはブラウザの localStorage にだけ保存されます。

```bash
npm install
npm run dev
```

## Slack連携

予定を追加したときに Slack に投稿するには、Incoming Webhook の URL を環境変数 `SLACK_WEBHOOK_URL` に設定します。
